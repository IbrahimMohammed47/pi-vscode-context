# Changelog

All notable changes to this project will be documented here.

## [0.1.0] - 2026-07-19

### Added

- Read-only `vscode_context` tool for active selections, visible cursor context, and bounded in-memory documents.
- Read-only `vscode_diagnostics` tool for active-file and workspace diagnostics.
- Authenticated loopback discovery across local VS Code windows with workspace and focus-aware selection.
- Bounded responses, abort handling, timeouts, and stale-window fallback.
